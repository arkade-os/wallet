# Link preview image

`public/arkade-og-image.png` is rendered from `og-image.html` at 1200×630 with a device scale factor of 2
(2400×1260), then reduced to a 256-colour palette, which keeps it near 55 KB without a visible change.

The page loads its fonts from files beside it: `firs.woff2` (TT Firs Neue Medium), `geist.woff2` and
`geist_mono.woff2` (copy the last two from `public/fonts/`). TT Firs Neue is licensed by Ark Labs and is not
committed; take it from the Arkade brand folder.

The balance, contacts and account in the card are illustrative and consistent with each other: $1,240.00 is
1,240,000 sats at $100,000 per Bitcoin.
